First release. A read-only MCP server for a Beszel hub, over stdio.

## Tools

- `fleet_status`: one row per system with status, headline numbers and structural problems. Each problem names the `system_detail` section that explains it.
- `system_detail`: one system, by Beszel's tabs: summary, core, network, disk, gpu, containers, services and updates. Container and service lists take `filter`, `problems_only`, `sort` and `limit`; problem rows are never cut.
- `metric_history`: trends over 1h to 30d, from the rollups Beszel's charts use. A true per-minute `peak` where Beszel stores one, `max_bucket_avg` elsewhere, and coverage that shows gaps.

## Token

- A dedicated `readonly` Beszel user with a long-lived impersonate token. Password login can stay off.
- macOS: `beszelscope token set|status|list|delete` keep the token in the Keychain through `/usr/bin/security`. Elsewhere: `BESZELSCOPE_TOKEN`.
- No code signing. Any program running as you can read the Keychain item without a prompt.

## Install

One binary per platform, built by GitHub Actions from this tag: `darwin_arm64` (Apple silicon), `linux_arm64`, `linux_amd64`, `windows_arm64` and `windows_amd64`.

1. Download yours and check it was built by this repo's release workflow:

   ```sh
   gh release download v0.1.0 -R agrmohit/beszelscope -p '*_<platform>*'
   gh attestation verify <file> -R agrmohit/beszelscope --signer-workflow agrmohit/beszelscope/.github/workflows/release.yml
   ```

   Or compare its SHA-256 with its line in `checksums.txt`.

2. Rename it to `beszelscope` (keep the `.exe` on Windows) and move it to a folder on your `PATH`. On macOS and Linux, make it executable with `chmod +x beszelscope`.
3. The binaries are not code signed, so a copy downloaded with a browser is flagged on first run. Clear the flag with `xattr -d com.apple.quarantine <file>` on macOS, or `Unblock-File <file>` in PowerShell on Windows. Copies fetched with `gh` or `curl` are not flagged.

Or install with Go 1.27 or later: `go install github.com/agrmohit/beszelscope/cmd/beszelscope@v0.1.0`.

Then follow [Connect it to your hub](https://github.com/agrmohit/beszelscope#connect-it-to-your-hub).

## Known limits

- Alerts are not shown: Beszel alerts belong to the user who made them.
- Package updates appear only for agents running natively on Linux.
- Short spikes can hide in long windows. Beszel keeps true peaks only for CPU, memory, total network traffic, disk activity and monitor latency.
